# Media Support Master 0.2.2 — Preview 1

Apple silicon preview, targeting macOS 15 or later. Intel is not supported by this installer. This build was checked on the maintainer's Apple silicon Mac; other supported macOS versions remain separate checks.

## Changes

- **Native XML export:** Python is no longer required for FCPXML. The Phu de nen den Motion template and preview images are included. A missing template installs automatically during XML export or from Settings; existing templates and user edits are preserved.
- **Integrated speech tools:** spoken-language detection and Vietnamese/English/Korean/Chinese script alignment use the bundled Whisper engine and native audio preparation. These paths do not require separately installed FFmpeg or Python for media readable by macOS.
- **Safer script alignment:** original text is kept, poor matches are rejected, long inputs use bounded alignment memory, and failed/cancelled/stale jobs preserve the current transcript. Japanese script alignment retains its existing MeCab workflow; Japanese subtitle layout is unchanged.
- **Model reuse:** an existing exact Whisper model can be verified and reused without another download, using a hard-link when possible. A changed model must be verified again.
- **Tool updates:** Settings → Integrated tools adds signed updates, previous-version recovery, template installation and CPU-only mode. Updates verify the publisher signature, architecture, compatibility, sizes and hashes before activation, and preserve current/bundled tools on failure.
- **Resource use:** audio extraction streams to 16 kHz mono PCM. Short recordings use CPU; longer recordings can use Metal. Helpers release model memory when the job ends, and cancellation reaches the helper.

## Install and setup

Download the **arm64 DMG**, open it, and drag **Media Support Master.app** into Applications. A relative-filename `.sha256` file is supplied beside the installer.

The app is **ad-hoc signed, not Developer ID signed or notarized**. macOS may require first-launch approval in Privacy & Security after you check the download's source. The app and updater do not disable macOS security.

- Online features still need your own provider credentials and may incur provider charges.
- The offline model is separate (about 1.62 GB), and is downloaded only when selected. Models, credentials, projects and voice caches are excluded from this installer.
- **Japanese script alignment retains its legacy Whisper/Python/MeCab environment.** Optional legacy refine/burn/cutting workflows may also need external tools. FFmpeg and Python runtimes are not bundled.
- Tool updates update components; they do not update the app itself. Existing customized Motion templates are preserved.
- Source/third-party notices are available in the public repository. The project's own code still has no selected open-source license; third-party components keep their own notices. The owner confirmed permission to distribute the Motion template.

## Validation

- **78/78 core checks passed**, plus native renderer, subtitle style, localization (626 keys × 5 languages), packaging, legacy alignment and FCPXML regression.
- Native integration checks cover five-language script fixtures, long inputs, mismatch rejection, token/language parsing, signatures, damaged files, rollback, template preservation, audio conversion and cancellation.
- **21 native/legacy XML fixtures** preserve equivalent timing/FPS/style/Unicode values.
- Synthetic English speech passed the real TEST app's alignment → language detection → XML pipeline with original text preserved. Vietnamese/Korean/Chinese synthetic recordings produced real timestamps that retained their original scripts. Japanese layout golden checks passed and its script runtime remains on the old path.
- Live tool update checks passed signed feed → download → verification → activation, busy-task protection and bundled recovery.
- Real user media, paid-provider calls, Final Cut import, fresh-machine installation and broad UI interaction checks were not performed in this release task. This remains a preview.
