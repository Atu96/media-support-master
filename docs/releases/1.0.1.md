# Media Support Master 1.0.1

## New-user setup

- Japanese script alignment includes an isolated ARM helper with the original MeCab algorithm, exact UniDic 2.1.2 runtime dictionary and force-abut behavior. Users do not install Python, MeCab, Homebrew, FFmpeg or a personal Tools directory for active subtitle workflows.
- Audio preparation and Whisper are integrated. The same separately downloaded Whisper model serves transcription, language detection and script alignment.
- Diagnostics check integrated tools, and the remaining video-burn service uses the native exporter.

## macOS and Apple AI

- Apple silicon; deployment target **macOS 15 or later**. Gemini/Groq and online dubbing remain usable without offline models on older supported systems.
- Apple local features check OS/device/model/language availability. Summaries use `SystemLanguageModel.default`, which refers to the OS's model; macOS27 uses its new on-device model. Output-language support is checked, and the prompt emphasizes preserving names/numbers/facts. Providers are not changed automatically.
- macOS26/27 is not required for ordinary API workflows. Every Japanese-helper Mach-O has minimum OS <=15 and no absolute host-Python/Homebrew dependency. Actual older-OS testing remains separate.

## Validation and limits

Packaged Japanese output matches the legacy algorithm byte-for-byte across six synthetic fixtures (text, wrap and timing). It runs under fresh HOME and system-only PATH. The TEST app passed Japanese alignment → language detection → XML on synthetic speech with original text preserved. Japanese subtitle layout golden checks and core/native/XML/style/localization/package/alignment regressions are retained.

The offline model (about 1.62 GB) remains a user-selected download, and online features need the user's credentials. Media must be readable by macOS. The Japanese helper loads only when needed and exits after the task; its dictionary increases installer/on-disk size rather than idle app memory. No model, provider key or user media is in the installer.

Install the arm64 DMG by dragging the app into Applications. Signing is ad-hoc, not Developer ID/notarized; macOS may require first-launch approval. Real user media, paid-provider calls, broad UI, older-OS/fresh-machine/FCP import tests are not certified by these fixture results.
