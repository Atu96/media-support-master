# Media Support Master 0.2.1 — Preview 1

First public preview for Apple silicon Macs. Requires macOS 15 or later; this build was checked on the maintainer's Apple silicon Mac, not across every supported OS version. Intel is not supported by this installer.

## Highlights

- Transcription, subtitle editing, translation, dubbing and export in one timeline.
- Background one/two-line subtitle layout with language-aware boundaries, including unpunctuated text. Japanese retains its existing separate layout.
- Voice catalogs grouped by country/language, model selection, provider progress/errors, and local dubbing cache management.
- Cue merging preserves available dubbing audio, with local audio merging when all selected cues have clips.
- English on fresh installations, five interface languages, and optional Support in About and the resource bar.
- Runtime scripts included in the app so moving it does not require the developer's source checkout.

## Install

Download the **arm64 DMG**, open it, and drag **Media Support Master.app** into Applications. The DMG also includes this guide and the README. Use the adjacent `.sha256` file to verify the download if needed.

This preview is ad-hoc signed and **not Developer ID signed or notarized**. macOS may block the first launch; after checking the download and its source, use the macOS Privacy & Security approval for the blocked app. No blanket security-disabling command is required.

## Setup and limits

- Online features need your own provider credentials and may incur provider charges. No credentials, user projects or voice caches are included.
- The small ARM Whisper engine and its MIT notices are bundled. The offline model is downloaded separately (about 1.62 GB).
- **FFmpeg is not bundled.** Some audio extraction/fallback workflows need a separately installed FFmpeg. Legacy wrappers can still require `~/Documents/Tools/Whisper_Native`, its Python environment, or the video-cutting scripts. Native subtitle editing, layout, rendering and dubbing do not require a source checkout.
- XML conversion requires Python 3. Final Cut Pro appearance also depends on the separately installed **Phu de nen den** Motion title. The optional subtitle-refine engine needs its Python dependencies.
- This is a preview, with automated fixture coverage; it has not been certified against every media file, language or paid provider. Perfect sentence understanding is not guaranteed. UI Support clicks and a fresh-machine installation remain manual checks.
- The project's own code has no selected open-source license. Public visibility does not replace a license; third-party components retain their notices.

## Validation

The release gate runs offline core/native-renderer/style/localization/FCPXML/alignment/package checks, compiles the ARM app, verifies its ad-hoc signature and the DMG, and checks the mounted bundle and source stamp. Exact results and the artifact checksum are recorded when the release is published. No API quota is consumed by these checks.
